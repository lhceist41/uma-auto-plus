# Story Unlocked fixture provenance

A full-width crop of a 1080x1920 `adb screencap` frame (true RGB) from MuMu, game version 1.35.2, taken on 2026-10-20 when a
Team Trials session stopped on the dialog. It pins the Close button the shared dialog handler dismisses the dialog with, in
`StoryUnlockedDialogFixtureTest`.

| Fixture | Source rows | Shows |
|---|---|---|
| story_unlocked_close_row.png | y 1180 to 1320 | The "Story Unlocked" dialog that opens over the Team Trials results after a match, when a trainee's story episode unlocks: its message ("You unlocked a new Umamusume story episode.") and its only button, Close. The episode card above it, which opens the story, is left out. |

A second capture of the same dialog two matches later (another trainee's episode) gave a byte-identical crop, so one file stands for both.
The crop holds no trainer name, rank, ID or friend code; the blurred results screen, the title banner and the episode card are left out.
