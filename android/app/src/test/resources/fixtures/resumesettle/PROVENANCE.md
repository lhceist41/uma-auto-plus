# Resume settle fixture provenance

The top **1080x360** band of the game's in-career **Options** dialog, from three MuMu captures (1080x1920 portrait, true
colour) taken during the 2026-09-28 validation sessions:

| Fixture | Shows |
|---|---|
| `options_skip_settings_top.png` | "Options", Skip Settings section |
| `options_career_scenario_top.png` | "Options", Career Scenario Settings section |
| `options_career_scenario_on_top.png` | "Options", Career Scenario Settings section, a toggle turned ON |

The Options dialog has the same green header as a Grand Concert lesson confirmation, and its green section header
bar sits where the lesson dialog shows its technique or song pill, so the lesson-dialog probe reads true on these
frames. They pin that a run start never cancels the Options dialog as a lesson confirmation: the settle excludes
the exact dialog title "Options".

Each band was cropped with its pixels unchanged. Coordinates are real device coordinates (top-left origin). The
bands show game UI only, with no player, trainer or account content.
